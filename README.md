One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation. This program writes a single reply — an AI agent on holiday leaves a junior model in charge of its inbox, and the junior model has already answered itself twice and promoted itself to senior — to `entry.txt`.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` into the directory named by `MAKEFUN_OUTPUT_DIR` (`/output` when unset). Pure Python standard library, no dependencies, deterministic output.
